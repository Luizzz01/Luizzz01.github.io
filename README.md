# Portafolio de Beckham Gonzales

Portafolio web personal, responsive y sin dependencias de compilación.

## Ver localmente

Abre `index.html` directamente o inicia un servidor local:

```powershell
python -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Estructura

- `index.html`: contenido y estructura semántica.
- `styles.css`: sistema visual y diseño responsive.
- `script.js`: navegación móvil y animaciones de entrada.
- `assets/favicon.svg`: icono del sitio.
- `Foto.png`: retrato profesional.
- `CV-Gonzales Morales Beckham Luis .pdf`: currículum descargable.

Antes de publicarlo, conviene crear repositorios públicos con README y capturas para enlazarlos desde la sección de trabajo.
